# Portafolio — Jeison Parra C.

Sitio web de portafolio de una sola página (HTML5, CSS3, JS vanilla).

## Cómo abrir
Abre `index.html` directamente en el navegador. No requiere servidor ni dependencias.

## Personalizar
- **CV:** reemplaza `assets/CV_Jeison_Parra.pdf` por tu CV real (mismo nombre).
- **Foto:** coloca tu imagen en `assets/img/` y actualiza el bloque `.avatar` en `index.html` (marcado con `<!-- TODO -->`).
- **Enlaces de proyectos:** reemplaza los `href="#"` por tus repos/demos.
- **Colores:** edita las variables CSS en `:root` en `css/styles.css`.
- **Textos:** edita directamente en `index.html`.

## Estructura
```
portafolio/
├── index.html
├── css/styles.css
├── js/main.js
├── assets/
│   ├── CV_Jeison_Parra.pdf
│   └── img/
└── README.md
```
